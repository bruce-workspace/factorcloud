# FactorCloud case study template

This is the **reference case study** the other portfolio templates are built from: FactorCloud x Integra Funding Solutions. It holds real customer copy, not placeholders.

- **Source of truth (edit here):** [Figma, TEMPLATE - FactorCloud](https://www.figma.com/design/XBHSe0P0q9eZKRtkgdw9bV/Case-Study?node-id=1-293)
- **Snapshot:** [`case-study-template.pdf`](case-study-template.pdf), 21 pages exported from Figma on 2026-10-28

The PDF is a read-only snapshot. Make changes in Figma and re-export; don't edit the PDF.

## Who the template is written for

Integra Funding Solutions, a bank-owned factor (customer copy is final, approved content).

## How to use it

1. In Figma, duplicate the template page (right-click the page, Duplicate) and rename it for the customer.
2. Keep the layout and section order; replace copy section by section with the new customer's story.
3. Swap the logo placeholder and the headshot placeholder for real assets.
4. Check the finished copy against the brand guidelines in `brand/` before it goes out.
5. Export slides as PDF (File, Export frames to PDF) for sharing.

## Brand applied

- **Type:** Syne (headlines), Inter (body), Geist Mono (eyebrows and labels)
- **Color:** Near-black `#07070A` background, `#121216` cards, gold `#E8B545` accent, warm white `#FFFCF7` text
